# QGC_KevinJiang v1.3.1

Release date: 2026-08-15

QGC_KevinJiang v1.3.1 is an internal Windows maintenance release for GRobot project members, based on QGroundControl v5.0.8. It keeps the stable `QGC_KevinJiang` application identity and supports in-place upgrades while retaining user settings.

## Highlights

- Fixed firmware-backed joystick actions failing to appear when the button page was opened before the vehicle parameter download completed.
- Fixed unrelated button rows incorrectly appearing as the final QGC action, such as `Gimbal Yaw Follow`.
- Kept valid ArduSub 4.8 enum entries when individual metadata values cannot be represented by an older parameter type, preserving actions such as `actuator_4_inc/dec`.
- Separated physical-output testing into three explicit paths: firmware Motor Test, direct thruster PWM, and servo jog.
- Direct thruster PWM now uses the physical SERVO output number, bypasses `SERVOx_FUNCTION` mapping and Motor Test cooldown, and returns to 1500 PWM.
- Servo jog validates `SERVOx_MIN/MAX`, uses an independent PWM and duration, and returns to `SERVOx_TRIM`.
- Added Windows installer version metadata and improved failure handling when uninstalling a previous version during an in-place upgrade.
- Updated application and Windows file version metadata to `1.3.1`.

The ArduSub 4.8 metadata, Servo12 Actuator4 gripper control, visible decoder-priority setting, and multi-RTSP startup improvements introduced for v1.3.0 remain included.

## Installation and in-place upgrade

Use:

- `QGC_v1.3.1_KevinJiang-installer.exe`

Close QGC before running the installer. The installer detects the previous `QGC_KevinJiang` installation, runs its uninstaller with user-data retention enabled, and installs v1.3.1 into the same location. Manual removal of the old version is not required.

After installation, confirm version `1.3.1` under Application Settings → Help. See `Servo12机械爪手柄配置说明.md` in the distribution package for the tested gripper parameter setup.

## Known limitations

- The local AI Python environment and model files are not included.
- RTSP URLs, safe gripper PWM limits, and joystick mappings must be configured for each vehicle.
- Multi-RTSP startup and Qt/GStreamer hardware-decoder behavior can still vary by GPU and driver. Use the visible decoder-priority setting as a compatibility fallback.
- Before testing any servo or thruster, ensure the vehicle is in a safe position and the movement area is clear.
