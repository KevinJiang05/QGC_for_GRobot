# QGC_KevinJiang v1.4.0｜赛后可靠性专项升级

各位老师、同学：

为提升 GRobot 在比赛与现场调试工况下的运行可靠性，团队在赛后两周内围绕**多路视频稳定性、链路异常感知与人工处置效率**完成了专项打磨，现正式发布 QGC_KevinJiang v1.4.0。

**1. 多路视频链路韧性升级**

重构并优化了多路视频的接入、重启与恢复工作流，针对重连后个别通道可能无法恢复画面的场景补强状态收敛和资源生命周期处理，提升复杂网络工况下的视频恢复一致性与连接状态可见性。

**2. 新增飞控—视频链路协同预警**

系统在飞控与视频链路建立稳定基线后，持续关注飞控心跳和视频新帧连续性。当出现飞控先断联、视频仍在输出等异常链路组合，或任一关键链路持续中断时，界面将弹出预警、记录事件并播放提示音，为操作员进入人工处置流程提供更及时的判断窗口。

该功能源于实战中的风险复盘：在疑似进水等异常情况下，飞控可能先于视频链路失联。操作员收到预警后，应结合现场状态迅速确认并按规程手动切断电源，尽可能降低持续通电造成元器件短路和扩大损坏的风险。

**3. 工程可靠性与可验证性完善**

本次同步修复了断链场景下的异步生命周期竞争问题，并完成连接监测、视频控制、相机管理和车辆链路的定向回归验证。发布包已通过安装、启动、运行时依赖、覆盖升级及完整性审计。
