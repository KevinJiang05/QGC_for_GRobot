# QGC_KevinJiang v2.0.0

发布日期：2026-10-07。

本版本面向 GRobot 项目成员，基于 QGroundControl v5.1.5 二次开发。

## 更新摘要

- 升级上游及 Qt、GStreamer，保留 DeepShark 四路视频、AI 和 ArduSub 定制功能。
- 主页面直接显示解锁／上锁和心跳检查；手柄设置整理为常规、按钮分配、校准、高级四页。
- 补齐常用界面中文，退出程序增加确认，合并重复的连接告警设置入口。
- 改善视频解码边缘、跨流纹理隔离，以及主窗口缩放时的视频帧积压与输出切换。
- 菜单底部版本信息精简为 `Kevin 2.0.0`。

## 从 1.5.0 升级

1. 退出 QGC，备份 `%APPDATA%\KevinJiang\` 整个目录，并保存原 1.5.0 安装包。
2. 运行 `QGC_v2.0.0_KevinJiang-installer.exe`，沿用原安装目录，无需先手动卸载。
3. 在菜单底部或“应用设置 → 帮助”确认版本，并核对视频地址、应用设置和手柄映射。

安装器以保留用户数据的方式替换旧程序。正式版保持原应用身份和配置版本；
四路摄像头设置的存储键不变。Debug 候选使用独立配置，不能用其配置隔离行为
判断正式版升级结果。代码契约和暂存程序启动检查不等于已完成真实覆盖安装验收。

## 回退到 1.5.0

退出 2.0.0，运行保留的 1.5.0 安装包，沿用原目录；在首次启动 1.5.0 前恢复
升级前的配置备份。新版会迁移部分设置，不能保证直接读取新版配置可无损回退。
普通卸载可能删除配置，因此不建议通过“先普通卸载、再装旧版”回退。
