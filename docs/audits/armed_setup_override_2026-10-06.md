# ArduSub 解锁状态配置编辑开关

## 用户行为

- 入口：应用程序设置 → 常规 → **禁用安全限制**。
- 使用 AppSettings/SettingsFact 保存，默认关闭，切换无需重启。
- 开启后，仅实际使用 ArduSub 插件的水下机器人解除设置页的 armed/flying 编辑限制；其他固件和机型保持原有规则。
- 关闭后恢复组件原有编辑权限、手柄页面的解锁隐藏规则、后续连接的参数下载策略及电机页面进入时的自动上锁行为。
- 开启时允许正常获取参数；如果当前连接已经因解锁跳过参数下载，自动补下载。高延迟和日志回放策略不变，任务/围栏/集结点下载策略不变。
- 通用参数继续使用 Fact/ParameterManager。类型、范围、只读属性、写入回读、重启生效及飞控拒绝处理不变。

## 手柄及实际操作

- 普通手柄配置期间同时提供轴值/按键监控和载具控制发送；增加原子状态区分普通编辑与实际校准。
- 实际校准仍要求上锁；校准时保留配置独占采集，取消校准后恢复普通编辑期间的控制发送。遥控/手柄校准中途解锁会取消校准。
- 传感器页面可编辑参数，校准入口在开启覆盖且已解锁时仍拒绝执行，不提前改变校准状态或通信保护设置。
- 电机页面在开启覆盖时不再因进入页面自动上锁；电机测试明确启动/停止条件、推进器直接输出恢复流程及飞控失控保护不变。
- 正常关闭手柄时，管理器先改变启用状态，轮询线程稍后退出；对应守卫继续停止发送，取消把这个短暂状态记录为内部错误的警告。
