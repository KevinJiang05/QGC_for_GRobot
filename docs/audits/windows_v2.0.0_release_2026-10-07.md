## 与既有记录比较

1.5.0 成功审计 `20261005-182513` 为增量重试：配置 23.272 秒、编译
514.286 秒、部署及 NSIS 197.117 秒、最终校验 7.949 秒，总计约 743 秒。
本轮是新版首次 Release，程序、依赖、任务数量及包体均不同；因此不把
454.913 对比 514.286 秒解释成同源码的并行提速比例。

已实际确认的优化是 8 并发执行、正确记录头文件依赖、无改动构建快速跳过，
以及部署后先启动验证、仅一次部署／压缩。NSIS 仍采用原有 LZMA 设置；本轮
压缩输入约 436.7 MB，旧版约 612.8 MB，压缩变快不能全部归因于流程拆分。
