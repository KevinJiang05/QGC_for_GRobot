# QGC_KevinJiang v1.0.0

Release date: 2026-06-01

QGC_KevinJiang v1.0.0 is the first stable internal GRobot release. It is based on QGroundControl v5.0.8 and adds DeepShark video workflow support, optional local AI detection integration, and Windows installer packaging.

## New Features

- Added DeepShark four-channel RTSP video panel.
- Added configurable camera names and RTSP URLs for front, left, right, and rear views.
- Added DeepShark status panel with per-camera connection state and retry controls.
- Added optional YOLO AI detection overlay.
- Added built-in AI settings, environment check, and AI start/stop/restart controls.
- Added GRobot application icon and Windows installer branding.
- Added Help page attribution for the QGC_KevinJiang build.

## Fixes And Packaging Changes

- Fixed RTSP AI detection startup for camera URLs such as `.sdp?real_stream` by routing stream URLs through an Ultralytics `.streams` input file.
- Removed old built-in AI test RTSP defaults; installer defaults leave RTSP URLs empty.
- Packaged lightweight AI bridge scripts into the Windows install directory under `bin/ai_detection`.
- Kept large Python dependencies and YOLO model files outside the installer.
- Disabled QGC application update prompts for this internal build.
- Prevented native QGC video settings from automatically switching from disabled to UDP h.264 after vehicle connection.

## Installation

Install using the GitHub Release asset:

- `QGC_v1.0.0_KevinJiang-installer.exe`

Do not commit the installer into the source repository. It should remain a Release attachment.

## Optional AI Setup

AI detection requires a local Python environment with:

- `ultralytics`
- `torch`

The user also needs a local YOLO model file, for example:

- `yolov8n.pt`
- a custom trained `.pt` model

Configure the Python executable and model path in QGC Video settings, then run the environment check before starting AI.

## Known Limitations

- AI dependencies and model files are not bundled with the installer.
- AI performance depends on the user's local Python, PyTorch, CUDA, GPU, and network camera environment.
- RTSP camera discovery is not automatic in v1.0.0; camera URLs must be entered manually.
- This is an internal GRobot distribution and is not an official QGroundControl release.

## Provenance

QGC_KevinJiang v1.0.0 is based on QGroundControl v5.0.8. The upstream Git history is preserved to keep source provenance, licensing, and future traceability clear.
