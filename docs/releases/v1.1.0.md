# QGC_KevinJiang v1.1.0

Release date: 2026-07-06

QGC_KevinJiang v1.1.0 is an internal GRobot update based on QGroundControl v5.0.8. It keeps the same application identity as v1.0.0, so the Windows installer upgrades the existing QGC_KevinJiang installation instead of installing a second copy.

## New Features

- Added a Panorama video layout: one main video stream on top and three auxiliary streams below.
- Added drag-and-drop video tile swapping in the DeepShark video panel.
- Added a persistent right-side preview window that can switch between RTSP 1 and the 3D attitude view.
- Improved the ROV 3D attitude model and added X/Y/Z axes on a light background.
- Added an AUV mission workspace with a satellite-map mission preview and debug speed multiplier.

## Fixes And Packaging Changes

- Kept the NSIS application identity, install directory, shortcuts, and uninstall key stable as `QGC_KevinJiang`.
- Preserved upgrade behavior from v1.0.0 by uninstalling the previous version while leaving user data in place.
- Updated application and Windows file version metadata to `1.1.0`.
- Kept optional AI dependencies and model files outside the installer.

## Installation

Install using the GitHub Release asset:

- `QGC_v1.1.0_KevinJiang-installer.exe`

If v1.0.0 is already installed, close QGC first, then run the v1.1.0 installer. The installer should upgrade the existing QGC_KevinJiang installation and preserve user configuration.

## Known Limitations

- AI dependencies and model files are not bundled with the installer.
- RTSP camera URLs still need to be configured by each operator.
- This is an internal GRobot distribution and is not an official QGroundControl release.

## Provenance

QGC_KevinJiang v1.1.0 is based on QGroundControl v5.0.8. The upstream Git history is preserved for source provenance, licensing, and future traceability.
