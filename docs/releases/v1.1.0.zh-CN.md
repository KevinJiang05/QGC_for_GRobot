# QGC_KevinJiang v1.1.0

发布日期：2026-07-06

QGC_KevinJiang v1.1.0 是面向 GRobot 内部使用的更新版本，基于 QGroundControl v5.0.8 二次开发。该版本保持与 v1.0.0 相同的应用身份，因此 Windows 安装包会升级已有的 QGC_KevinJiang，而不是安装成第二个并存版本。

## 新增功能

- 新增全景视频布局：上方显示一路主视频流，下方显示三路辅助视频流。
- DeepShark 视频面板支持拖动视频画面以交换位置。
- 右侧常态化预览窗口支持在 RTSP 1 和 3D 姿态视角之间切换。
- 优化 ROV 3D 姿态模型，并在浅色背景下显示 X/Y/Z 坐标轴。
- 新增 AUV 任务工作区，支持卫星地图任务预览和调试倍速。

## 修复与打包变化

- 保持 NSIS 应用身份、安装目录、快捷方式和卸载注册表键为 `QGC_KevinJiang`。
- 保留从 v1.0.0 升级的行为：安装时会卸载旧版本程序文件，同时保留用户配置数据。
- 应用版本号和 Windows 文件版本元数据已更新为 `1.1.0`。
- AI 依赖和模型文件仍不打包进安装包，需要用户按需配置本地环境。

## 安装方式

请使用 GitHub Release 或分发目录中的安装包：

- `QGC_v1.1.0_KevinJiang-installer.exe`

如果电脑上已经安装 v1.0.0，请先关闭 QGC，再运行 v1.1.0 安装包。安装程序应升级现有的 QGC_KevinJiang，并保留用户配置。

## 已知限制

- AI 依赖和模型文件不随安装包一起分发。
- RTSP 摄像头地址仍需要每位操作者根据现场设备自行配置。
- 本版本是 GRobot 内部发行版本，不是官方 QGroundControl 发行版。
