# QGC_KevinJiang v1.1.1

Release date: 2026-07-08

QGC_KevinJiang v1.1.1 is an internal GRobot maintenance update based on QGroundControl v5.0.8. It keeps the same application identity as v1.0.0 and v1.1.0, so the Windows installer upgrades the existing QGC_KevinJiang installation instead of installing a second copy.

## Update Summary

- Updated application and Windows file version metadata to `1.1.1`.
- Preserved the NSIS application identity, install directory, shortcuts, and uninstall key as `QGC_KevinJiang`.
- Preserved upgrade behavior from earlier QGC_KevinJiang versions while leaving user data in place.
- Kept optional AI dependencies and model files outside the installer.

## Installation

Install using the GitHub Release asset:

- `QGC_v1.1.1_KevinJiang-installer.exe`

If an earlier QGC_KevinJiang version is already installed, close QGC first, then run the v1.1.1 installer. The installer should upgrade the existing QGC_KevinJiang installation and preserve user configuration.

## Known Limitations

- AI dependencies and model files are not bundled with the installer.
- RTSP camera URLs still need to be configured by each operator.
- This is an internal GRobot distribution and is not an official QGroundControl release.

## Provenance

QGC_KevinJiang v1.1.1 is based on QGroundControl v5.0.8. The upstream Git history is preserved for source provenance, licensing, and future traceability.
