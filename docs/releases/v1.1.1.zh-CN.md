# QGC_KevinJiang v1.1.1

发布日期：2026-07-08

QGC_KevinJiang v1.1.1 是面向 GRobot 内部使用的维护更新版本，基于 QGroundControl v5.0.8 二次开发。该版本保持与 v1.0.0 和 v1.1.0 相同的应用身份，因此 Windows 安装包会升级已有的 QGC_KevinJiang，而不是安装成第二个并存版本。

## 更新摘要

- 应用版本号和 Windows 文件版本元数据已更新为 `1.1.1`。
- 保持 NSIS 应用身份、安装目录、快捷方式和卸载注册表键为 `QGC_KevinJiang`。
- 保留从旧版 QGC_KevinJiang 升级的行为：安装时会替换旧版本程序文件，同时保留用户配置数据。
- AI 依赖和模型文件仍不打包进安装包，需要用户按需配置本地环境。

## 安装方式

请使用 GitHub Release 或分发目录中的安装包：

- `QGC_v1.1.1_KevinJiang-installer.exe`

如果电脑上已经安装旧版 QGC_KevinJiang，请先关闭 QGC，再运行 v1.1.1 安装包。安装程序应升级现有的 QGC_KevinJiang，并保留用户配置。

## 已知限制

- AI 依赖和模型文件不随安装包一起分发。
- RTSP 摄像头地址仍需要每位操作者根据现场设备自行配置。
- 本版本是 GRobot 内部发行版本，不是官方 QGroundControl 发行版。

## 来源说明

QGC_KevinJiang v1.1.1 基于 QGroundControl v5.0.8 二次开发。项目保留上游 Git 历史，用于来源追踪、许可证合规和后续维护。
