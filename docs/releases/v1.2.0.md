# QGC_KevinJiang v1.2.0

Release date: 2026-08-10

QGC_KevinJiang v1.2.0 is an internal GRobot update based on QGroundControl v5.0.8. It retains the same application identity as the earlier QGC_KevinJiang releases, so the Windows installer upgrades the existing installation rather than installing a second copy.

## Update Summary

- Added DeepShark video workspace enhancements, including a panoramic layout and drag-to-reorder video tiles.
- Added AUV mission and debug presentation workflows, including mission path display, task controls, debug speed, and emergency-stop confirmation.
- Added a 3D attitude workspace and a compact side view that can switch between RTSP channel 1 and the 3D view.
- Optimized the ground-control-to-vehicle connection path and improved connection error handling.
- Added compatibility improvements for newer ArduSub firmware and resolved related setup, parameter, and runtime error reports.
- Improved vehicle setup, sensor diagnostics, thruster mapping layout, and ArduSub arming checks.
- Updated application and Windows file version metadata to `1.2.0`.
- Preserved the NSIS application identity, install directory, shortcuts, and uninstall key as `QGC_KevinJiang`.

## Installation and Upgrade

Install using the release asset:

- `QGC_v1.2.0_KevinJiang-installer.exe`

If an earlier QGC_KevinJiang version is already installed, close it first, then run the v1.2.0 installer. It uses the same Windows installation identity and should replace the installed program files in place while retaining user configuration.

## Known Limitations

- AI dependencies and model files are not included in the installer; operators configure local Python and model paths when AI detection is required.
- RTSP camera URLs are site-specific and need to be configured for the target equipment.
- This is an internal GRobot distribution, not an official QGroundControl release.

## Provenance

QGC_KevinJiang v1.2.0 is based on QGroundControl v5.0.8. The upstream Git history remains in this repository for traceability and license compliance.
