# QGC_KevinJiang v1.2.0

发布日期：2026-08-10

QGC_KevinJiang v1.2.0 是面向 GRobot 内部使用的更新版本，基于 QGroundControl v5.0.8 二次开发。本版本保持与此前 QGC_KevinJiang 一致的应用身份，因此 Windows 安装包会升级现有安装，而不会安装第二套并存程序。

## 更新摘要

- 优化 DeepShark 视频工作区，新增全景布局，并支持拖动调整视频窗位置。
- 增加 AUV 任务与调试演示流程，包括任务路径显示、任务控制、调试倍速和急停二次确认。
- 增加 3D 姿态工作区，以及可在 RTSP 第一路和 3D 视角间切换的侧边小窗。
- 优化地面站与设备之间的连接链路，并改进连接异常的处理。
- 增强对新版 ArduSub 固件的兼容性，解决相关设备设置、参数和运行时报错问题。
- 改进设备设置、传感器诊断、推进器映射布局和 ArduSub 解锁检查。
- 应用及 Windows 文件版本已更新为 `1.2.0`。
- 保持 NSIS 应用身份、安装目录、快捷方式和卸载注册表项为 `QGC_KevinJiang`。

## 安装与升级

请使用发行包：

- `QGC_v1.2.0_KevinJiang-installer.exe`

若电脑中已安装任意旧版 QGC_KevinJiang，请先关闭程序，再运行 v1.2.0 安装包。安装器使用相同的 Windows 安装身份，会原位替换程序文件，并保留用户配置。

## 已知限制

- AI 依赖和模型文件不包含在安装包中；需要使用 AI 检测时，操作人员需配置本地 Python 与模型路径。
- RTSP 摄像头地址与现场设备相关，需要在目标设备上配置。
- 本版本为 GRobot 内部分发版本，不是官方 QGroundControl 发行版。
