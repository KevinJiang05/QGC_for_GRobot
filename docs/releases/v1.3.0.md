# QGC_KevinJiang v1.3.0

Release date: 2026-08-14

QGC_KevinJiang v1.3.0 is an internal Windows update for GRobot project members, based on QGroundControl v5.0.8. The installer keeps the stable `QGC_KevinJiang` application identity, so it can upgrade an existing installation in place while preserving user settings.

## Highlights

- Added direct Servo output jog support for validating servo channels, PWM values, and trim positions during setup.
- Added ArduSub 4.8 parameter metadata and version selection support, including Actuator4 and onboard joystick button functions.
- Added Servo12 gripper control through `actuator_4_inc/dec`, allowing hold-to-move and release-to-hold operation.
- Exposed the video decoder priority setting for selecting default, software, or hardware decoding on different GPU and driver combinations.
- Improved multi-RTSP startup and reconnect handling to reduce channels remaining unavailable after application startup.
- Updated application and Windows file version metadata to `1.3.0`.
- Preserved the application name, install directory, shortcuts, and uninstall registry identity as `QGC_KevinJiang`.

## Installation and in-place upgrade

Use:

- `QGC_v1.3.0_KevinJiang-installer.exe`

Close QGC before running the installer. The installer detects the previous installation, removes the old program files, and installs v1.3.0 into the same location while retaining user settings. Manual removal of the old version is not required.

After installation, confirm version `1.3.0` under Application Settings → Help. See `Servo12机械爪手柄配置说明.md` in the distribution package for the tested gripper parameter setup.

## Known limitations

- The local AI Python environment and model files are not included.
- RTSP URLs, safe gripper PWM limits, and joystick mappings must be configured for each vehicle.
- Before testing any servo or thruster, ensure the vehicle is in a safe position and the movement area is clear.
