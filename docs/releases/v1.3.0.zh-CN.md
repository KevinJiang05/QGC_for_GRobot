# QGC_KevinJiang v1.3.0

发布日期：2026-08-14

QGC_KevinJiang v1.3.0 是面向 GRobot 项目成员的 Windows 更新版本，基于 QGroundControl v5.0.8 二次开发。安装器继续使用固定的 `QGC_KevinJiang` 应用身份，因此可以覆盖升级已经安装的旧版本，并保留用户配置。

## 更新摘要

- 增加 Servo 输出点动功能，便于在设备配置阶段安全验证舵机通道、PWM 和回中位置。
- 加入 ArduSub 4.8 参数元数据及版本选择支持，可在界面中识别 Actuator4 和飞控原生手柄按键功能。
- 支持通过 `actuator_4_inc/dec` 控制 Servo12 机械爪，实现按住运动、松键保持当前位置。
- 显式显示“视频解码优先级”设置，便于在不同显卡和驱动环境下切换默认、软件或硬件解码策略。
- 改进多路 RTSP 视频启动和重连处理，降低程序刚启动时部分通道未进入正常播放状态的概率。
- 应用及 Windows 文件版本更新为 `1.3.0`。
- 保持应用名称、安装目录、快捷方式和卸载注册表项为 `QGC_KevinJiang`。

## 安装与覆盖升级

请使用：

- `QGC_v1.3.0_KevinJiang-installer.exe`

安装前请先退出正在运行的 QGC。直接运行安装包即可：安装器会检测并卸载旧版程序文件，然后在原目录安装 v1.3.0；用户配置数据会保留，不需要先手动卸载旧版本。

安装完成后，可在“应用设置 → 帮助”中确认版本为 `1.3.0`。机械爪参数设置方法见发行包内的 `Servo12机械爪手柄配置说明.md`。

## 已知限制

- AI Python 环境和模型文件不包含在安装包中。
- RTSP 地址、机械爪 PWM 安全范围和手柄按键映射仍需根据每台机器配置。
- 首次测试舵机或推进器前，必须确认设备处于安全位置且运动范围内无人、无障碍物。
