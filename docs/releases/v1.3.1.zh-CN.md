# QGC_KevinJiang v1.3.1

发布日期：2026-08-15

QGC_KevinJiang v1.3.1 是面向 GRobot 项目成员的 Windows 维护版本，基于 QGroundControl v5.0.8 二次开发。安装器继续使用固定的 `QGC_KevinJiang` 应用身份，支持覆盖升级并保留用户配置。

## 更新摘要

- 修复在飞控参数尚未下载完成时进入手柄页面，固件原生按钮动作不能显示的问题。
- 修复无关按钮行可能错误显示为最后一个 QGC 动作（例如 `Gimbal Yaw Follow`）的问题。
- 当个别 ArduSub 4.8 元数据枚举无法由旧参数类型表示时，继续保留其他有效枚举，避免 `actuator_4_inc/dec` 等动作整组消失。
- 将物理输出测试明确拆分为飞控原生 Motor Test、推进器直发 PWM 和舵机点动三条路径。
- 推进器直发 PWM 按物理 SERVO 输出编号工作，不经过 `SERVOx_FUNCTION` 映射，也不等待 Motor Test 冷却，结束后回到 1500 PWM。
- 舵机点动会校验 `SERVOx_MIN/MAX`，使用独立 PWM 和时长，结束后回到 `SERVOx_TRIM`。
- 增加 Windows 安装器版本信息，并完善覆盖升级时旧版本卸载失败的处理。
- 应用及 Windows 文件版本更新为 `1.3.1`。

v1.3.0 加入的 ArduSub 4.8 元数据、Servo12 Actuator4 机械爪控制、显式视频解码优先级和多路 RTSP 启动改进继续保留。

## 安装与覆盖升级

请使用：

- `QGC_v1.3.1_KevinJiang-installer.exe`

安装前请先退出 QGC。安装器会检测已有的 `QGC_KevinJiang`，以保留用户数据的方式运行旧版卸载器，然后在原目录安装 v1.3.1；不需要先手动卸载旧版本。

安装完成后，可在“应用设置 → 帮助”中确认版本为 `1.3.1`。机械爪参数设置方法见发行包内的 `Servo12机械爪手柄配置说明.md`。

## 已知限制

- AI Python 环境和模型文件不包含在安装包中。
- RTSP 地址、机械爪 PWM 安全范围和手柄按键映射仍需根据每台机器配置。
- 多路 RTSP 启动和 Qt/GStreamer 硬件解码仍可能受显卡与驱动影响，可使用显式显示的“视频解码优先级”作为兼容性回退设置。
- 首次测试舵机或推进器前，必须确认设备处于安全位置且运动范围内无人、无障碍物。
