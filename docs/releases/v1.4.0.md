# QGC_KevinJiang v1.4.0

Release date: 2026-09-09

QGC_KevinJiang v1.4.0 is an internal Windows release for GRobot project members, based on QGroundControl v5.0.8. It retains the stable `QGC_KevinJiang` application identity and upgrades an existing installation in place while retaining user settings.

## Highlights

- Added optional DeepShark connection monitoring. After a vehicle and enabled video streams have first reached a stable connection, it detects a lost flight-controller heartbeat or a stream that has stopped receiving new frames.
- Added a concise Fly View connection-status banner, an on-demand details panel, acknowledgement/recovery records, configurable thresholds, and local alert tones. A connection alert is an operational prompt for inspection, not a diagnosis of flooding or hardware failure.
- Improved DeepShark video recovery and added diagnostics for multi-stream connection state.
- Fixed lifecycle races exposed by MockLink disconnection, including a camera-information retry callback that could outlive its camera manager.
- Added focused DeepShark connection-monitor, video-controller, camera-manager, and vehicle-link regression coverage.

## Installation and in-place upgrade

Use:

- `QGC_v1.4.0_KevinJiang-installer.exe`

Close QGC before running the installer. The installer detects an existing `QGC_KevinJiang` installation, runs its uninstaller with user-data retention enabled, then installs v1.4.0 into the same location. Manual removal of an earlier version is not required.

After installation, confirm version `1.4.0` under Application Settings -> Help.

## Known limitations

- The alert monitors observed heartbeat and video-frame continuity; it does not diagnose the cause of a disconnection.
- The monitor only provides local operational prompts and recovery records; it does not change flight-controller parameters or issue control commands.
- The local AI Python environment and model files are not included.
- RTSP URLs, safe gripper PWM limits, and joystick mappings must be configured for each vehicle.
- Multi-RTSP startup and Qt/GStreamer hardware-decoder behavior can still vary by GPU and driver.
