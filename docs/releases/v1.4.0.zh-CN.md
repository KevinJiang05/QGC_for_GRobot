# QGC_KevinJiang v1.4.0

发布日期：2026-09-09

QGC_KevinJiang v1.4.0 是面向 GRobot 项目成员的 Windows 版本，基于 QGroundControl v5.0.8 二次开发。它继续使用固定的 `QGC_KevinJiang` 应用身份，可覆盖升级已有安装并保留用户配置。

## 更新摘要

- 新增可选的 DeepShark 异常断联监测：飞控与已启用的视频流先达到稳定连接后，监测飞控心跳中断和视频流停止接收新帧的情况。
- 新增飞行界面的一行连接状态提示、按需展开的详情面板、确认/恢复记录、可配置阈值及本地提示音。断联预警是现场检查提示，不等同于进水或硬件故障诊断。
- 改进 DeepShark 视频恢复，并补充多路视频连接状态诊断。
- 修复 MockLink 断开时暴露的生命周期竞争，包括摄像头信息重试回调可能在摄像头管理器销毁后继续访问的问题。
- 新增针对 DeepShark 连接监测、视频控制器、摄像头管理器及车辆链路的定向回归覆盖。

## 安装与覆盖升级

请使用：

- `QGC_v1.4.0_KevinJiang-installer.exe`

安装前请先退出 QGC。安装器会检测已有的 `QGC_KevinJiang`，以保留用户数据的方式运行旧版卸载器，再在原目录安装 v1.4.0；不需要手动卸载旧版本。

安装完成后，可在“应用设置 -> 帮助”中确认版本为 `1.4.0`。

## 已知限制

- 预警仅根据观测到的心跳和视频新帧连续性工作，不能诊断断联根因。
- 该监测只提供本地运行提示和恢复记录，不修改飞控参数、不下发控制指令。
- AI Python 环境和模型文件不包含在安装包中。
- RTSP 地址、机械爪 PWM 安全范围和手柄按键映射仍需按每台设备配置。
- 多路 RTSP 启动和 Qt/GStreamer 硬件解码仍可能受显卡与驱动影响。
