# QGC_KevinJiang v1.5.0

发布日期：2026-10-05

QGC_KevinJiang v1.5.0 是面向 GRobot 项目成员的 Windows 版本，基于 QGroundControl v5.0.8 二次开发。它继续使用固定的 `QGC_KevinJiang` 应用身份，可覆盖升级已有安装并保留用户配置。

## 更新摘要

- DeepShark 四路视频新增 RTSP 传输方式选择：自动（按地址）、TCP、UDP。设置适用于全部 RTSP 通道，保存后自动重连正在播放的视频，无需逐个修改地址。
- 修复 GStreamer 视频接收器的引用泄漏、地址清空后停止不完整、跨线程状态竞争及视频尺寸读取问题。
- AI 检测配置、进程管理和检测叠加归入 DeepShark 自定义插件；检测叠加统一在 DeepShark 视频面板展示，保留旧版叠加开关配置的读取兼容。
- 补充 AI 检测接收器、RTSP 传输方式及视频接收器生命周期的定向回归覆盖。
- 固定与现有 MAVLink 兼容的事件库依赖，避免干净构建时浮动依赖更新导致编译失败。

## 安装与覆盖升级

使用 `QGC_v1.5.0_KevinJiang-installer.exe`。安装前退出 QGC，运行安装包即可升级已有的 `QGC_KevinJiang`。安装器保留固定安装身份，并以保留用户数据的方式卸载旧程序；不需要手动卸载旧版。

安装完成后，在“应用设置 → 帮助”确认版本为 `1.5.0`。帮助页读取程序运行版本；安装器和程序版本由统一发布脚本同步。

## 发行验收

本次发布的验证状态、安装器 SHA-256 和运行日志以分发目录下 `release-audit/` 中的最终审计报告为准。最终报告必须为 `succeeded`，六个步骤均通过后才建议分发。

## 已知限制

- 视频接收器缺陷修复不代表已证明解决现场偶发的短时卡顿；长时间、多路真实 RTSP 工况仍需现场验证。
- AI Python 环境、CUDA 依赖和模型文件不包含在安装包中，需在每台设备上另行配置。
- RTSP 地址、机械爪 PWM 范围和手柄映射仍需按设备配置。
- 发布审计检查暂存程序启动和覆盖升级契约，不代替真实设备验收或本机实际覆盖安装测试。
- 当前安装包不应用 Authenticode 签名。
