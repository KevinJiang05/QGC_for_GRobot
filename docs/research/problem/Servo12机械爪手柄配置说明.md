# Servo12 机械爪手柄配置说明

适用范围：机械爪接在飞控 **Servo12**、飞控使用本项目相同定制版 ArduSub 固件，并安装 KevinQGC 1.3.1 或更高版本。

目标效果：按住手柄 9/10 号键时机械爪向两个方向运动；松开按键后停在当前位置。

## 一、修改飞控参数

连接飞控后进入“载具设置 → 参数”，依次搜索并设置：

| 参数 | 设置值 | 说明 |
| --- | ---: | --- |
| `SERVO12_FUNCTION` | `187`（Actuator4） | 将物理 Servo12 输出映射为逻辑 Actuator4 |
| `SERVO12_MIN` | `1050` | 一个方向的安全端点 |
| `SERVO12_MAX` | `1350` | 另一个方向的安全端点 |
| `SERVO12_TRIM` | `1200` | 飞控启动时的初始位置 |
| `SERVO12_REVERSED` | `0`（Normal） | 若实际方向相反，可改为 Reversed，或互换两个按键功能 |
| `BTN9_FUNCTION` | `116`（actuator_4_dec） | 按住 9 号键，逐步向 1050 方向运动 |
| `BTN10_FUNCTION` | `115`（actuator_4_inc） | 按住 10 号键，逐步向 1350 方向运动 |
| `BTN9_SFUNCTION` | `0`（Disabled） | 不使用换挡功能 |
| `BTN10_SFUNCTION` | `0`（Disabled） | 不使用换挡功能 |

修改完成后等待参数写入，并重新启动飞控和 KevinQGC。

## 二、在手柄页面确认

进入“载具设置 → 游戏手柄 → 按钮分配”，确认：

- 9 号键显示 `actuator_4_dec`；
- 10 号键显示 `actuator_4_inc`；
- 两个按键的换挡功能均为 `Disabled`。

不要选择 `Gripper Open/Close`，也不要选择 `actuator_4_min/max_momentary`。后者松开按键后会自动回到中间位置，不能实现“松手保持”。

## 三、调整运动速度

搜索参数 `ACTUATOR4_INC`：
推荐0.180
- 数值越大，每次递增/递减的幅度越大，机械爪运动越快；
- 数值越小，运动越慢、微调越细；
- 建议从当前值小幅增加，每次修改后短按测试，避免一次调得过大。

`SERVO_RATE` 是 PWM 输出刷新率，不是这套按键控制的主要速度参数，不建议用它调机械爪速度。

## 四、测试与注意事项

1. 修改前先备份整机参数。
2. 首次测试时确保推进器和机械爪周围无人、无障碍物，并先短按确认方向。
3. 9 号键应向 1050 方向运动，10 号键应向 1350 方向运动；松键后应保持当前位置。
4. 如果机械结构不同，只能在确认安全行程后调整 `SERVO12_MIN/MAX`，不要直接照搬更大的行程。
5. 采用 Actuator4 方案后，`GRIP_GRAB`、`GRIP_RELEASE` 等 `GRIP_*` 参数不再控制 Servo12。
