# QGC 手柄抓包脚本使用说明

脚本：`capture_qgc_manual_control.cmd`

1. 保持机器机械固定、飞控未解锁，不按 Xbox 的任何按钮。
2. 右键脚本，选择“以管理员身份运行”。
3. 第一处 `Press any key to continue` 用于确认安全条件，按任意键后正式开始抓包。
4. 看到 `Capture is running` 后执行：油门回中、25% 后回中、50% 后回中、0% 后回中。
5. 操作完成后按任意键，脚本会停止抓包并转换为 `.pcapng`。
6. 输出文件位于上一级 `logs` 目录。

脚本只捕获 QGC 到 `192.168.1.200:4019` 的 TCP 数据，不发送 MAVLink 命令。
